MDDB Chat Widget - Dev Preview

This page demonstrates the embeddable chat widget. Click the chat icon in the bottom-right corner to open it.

The widget connects to the chat server at ws://localhost:11030/ws.

Usage

<script src="https://your-domain.com/mddb-chat.min.js"
  data-server="wss://chat.example.com/ws"
  data-scenario="assistant"
  data-theme="light"
  data-accent="#3B82F6"
  data-position="bottom-right">
</script>
