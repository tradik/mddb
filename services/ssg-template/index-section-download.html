What's New in v{{$.Vars.mddbVersion}}

  • One permission gate on every surface: with auth on, a key limited to one collection or one tenant can no longer read or write others over REST, gRPC, GraphQL or MCP, and admin on one collection no longer makes a global admin.
  • The real client IP behind a proxy: MDDB_TRUSTED_PROXIES, MDDB_CLIENT_IP_HEADER and PROXY protocol v1/v2. Behind a reverse proxy, set MDDB_TRUSTED_PROXIES when you upgrade, or every client shares the proxy's rate limit.
  • A result cap: a search returns at most MDDB_SEARCH_MAX_LIMIT results (1000 by default) and says "limitCapped": true when it lowered a request.
  • Elasticsearch-compatible subset: MDDB_ES_COMPAT=true mounts _search, _count, _doc and _bulk under /es, and refuses an unsupported clause by name.
  • Corpus packs and synced sources: install a collection read-only without re-embedding it, or keep one in step with a sitemap, a URL list or an S3 prefix.
  • Query decomposition and mddb-cli diagnose: queryDecomposition: "auto" searches a question with several needs part by part; the diagnose bundle is a tar.gz without user data to attach to an issue.
