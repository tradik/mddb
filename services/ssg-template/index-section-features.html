Why MDDB? #

One binary. Every protocol. AI-native from day one.

MDDB is an AI-native embedded document database written in Go, using BoltDB for storage. It accepts Markdown, plain text, HTML, PDF, DOCX, ODT, RTF, LaTeX, YAML, and Wikipedia XML dump documents, auto-converting everything to Markdown. All documents are stored with full revision history.

Core capabilities

  • Built-in MCP server with {{$.Vars.mcpTools}} tools — connects to Claude, Cursor, Windsurf, ChatGPT, Ollama, DeepSeek, Manus via stdio and HTTP transport
  • Geospatial search: R-tree and geohash indexes, radius and bounding-box queries, composable with full-text and vector search, optional postcode lookup
  • Transport options: TCP host:port or Unix Domain Socket (unix:/path.sock) for zero-network local deployments (PHP-FPM sidecars, cron, same-host panel)
  • TLS and mutual TLS (mTLS): user-supplied server cert/key, optional client CA bundle for certificate-based client authentication (MDDB_TLS_CLIENT_CA)
  • Vector/semantic search with 8 index algorithms: Flat (exact), HNSW, IVF, PQ, OPQ, SQ, SQ4, BQ, or algorithm: auto to let the server choose — OpenAI, Ollama, Cohere, Voyage AI embeddings or the offline lexical provider, with per-collection int8/int4 quantization (4-8x compression)
  • Full-text search with 8 modes (simple, boolean, phrase, wildcard, proximity, expression, range, fuzzy), TF-IDF, BM25, BM25F, PMISparse scoring, multi-language stemming (17 languages), typo tolerance, metadata pre-filtering
  • Hybrid search combining sparse (BM25) and dense (vector) with alpha blending or Reciprocal Rank Fusion
  • Zero-shot document classification using embedding cosine similarity
  • Custom MCP tools defined in YAML for domain-specific AI workflows
  • RAG pipeline: auto-embed on ingest, semantic retrieval, MCP exposure to LLMs
  • Memory RAG: conversational memory with session management, semantic recall, and summarization
  • Multi-protocol: HTTP/JSON REST API, HTTP/3, gRPC/Protobuf, GraphQL, Server-Sent Events, WebSocket streaming (via mddb-chat), MCP (Streamable HTTP / SSE / stdio)
  • Elasticsearch-compatible subset under /es (MDDB_ES_COMPAT=true): search, count, document and bulk calls for existing Elasticsearch clients
  • Multi-format upload: 20 file formats — .md, .txt, .html, .pdf, .docx, .odt, .rtf, .tex, .yaml, .xlsx, .ods, .csv, .tsv, .pptx, .odp, .epub, .eml, .mbox and more — with auto-conversion to Markdown
  • Corpus packs: a collection built once and installed read-only anywhere, without re-embedding or reindexing
  • Synced sources: a cron rule keeps a collection in step with a sitemap, a URL list or an S3 prefix
  • Wikipedia XML dump import: stream multi-GB MediaWiki dumps with wikitext-to-Markdown conversion, namespace filtering, batch processing
  • URL import: fetch and store documents from any URL
  • Document TTL with auto-expiry and background cleanup
  • Full revision history for every document
  • JWT authentication and RBAC authorization (opt-in)
  • Compliance-first (v2.9.15+): ISO 27001 / SOC 2 hardening built-in — audit log, AES-256-GCM at-rest encryption, HTTP+gRPC rate limiter, incident webhooks, and a single MDDB_PRODUCTION=true switch that refuses to boot without every control in place
  • Leader-follower replication with binlog streaming
  • Scheduled backups with retention and an S3 target; per-collection quotas, disk reserve and embedding budget
  • Behind a load balancer: trusted proxies (MDDB_TRUSTED_PROXIES) and PROXY protocol v1/v2 give rate limits and the audit log the real client IP
  • Automation: triggers, crons, webhooks, sentiment analysis, template variables
  • Multi-language support: same document key, multiple locales
  • Prometheus metrics, Grafana dashboard support and OpenTelemetry trace export
  • {{$.Vars.mddbBinarySize}} single binary, embedded BoltDB, zero external dependencies
  • Docker image: {{$.Vars.mddbDockerSize}} compressed, Alpine-based, with health checks
  • Aggregations: metadata facets (value counts) and date histograms with optional pre-filtering
  • Per-collection storage backends: BoltDB (default), in-memory (ephemeral), S3/MinIO — configurable via API and web panel
  • Web admin panel (React-based) with REST/GraphQL API toggle
  • PHP and Python client libraries

Hybrid Search Engine

Full-text with 8 search modes (simple, boolean, phrase, wildcard, proximity, expression, range, fuzzy) + vector search with 8 index types, or auto to let the server pick one for the collection. Multi-language stemming for 17 languages. Combine with alpha blending or Reciprocal Rank Fusion. Metadata pre-filtering, typo tolerance. Source code is searched as code and linked into a graph of calls, includes and references, from C and Go to Terraform and Kubernetes manifests.
